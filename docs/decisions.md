# Архитектурные решения

## 2026-10-20: Сначала пакет ROS 2 интерфейсов

Репозиторий начинается с отдельного пакета `swarm_interfaces`, чтобы все
рабочие узлы использовали явные контракты сообщений, проверяемые при сборке.
Пакет не зависит от специфичных сообщений PX4; телеметрия PX4 подключается
снаружи через `px4_msgs`.

## 2026-10-20: Соглашение о координатах

Позиции прикладного уровня используют ENU ROS/Gazebo. Преобразование в NED
PX4 выполняется только в autopilot bridge и никогда не зашивается неявно в
сообщения роя.

## 2026-10-20: Консервативная идентификация LiDAR

Начальные ID привязаны к стартовым областям из YAML. Далее применяется
предсказание постоянной скорости и EMA; неоднозначность приводит к invalid.
При длительной потере трек не назначается новой цели автоматически.
Ориентация ведомого по облаку не оценивается.
