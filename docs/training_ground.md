# Наземная разметка и неподвижные ориентиры

Модель `training_ground` добавляет ориентиры для наблюдения движения
аппаратов. Она рассчитана на существующую площадку размером 200 × 200 м
с поверхностью на высоте Z = 0. Начало модели должно совпадать с началом
площадки, а её оси — с осями мира.

Светлый серый фон покрывает площадку. Тонкие линии проходят через 2 м,
утолщённые — через 10 м. Красная ось соответствует X, синяя — Y.
В принятой системе координат мира X направлен на восток, Y на север.
Линии и оси лежат на высоте 0,002 м, фон — на высоте 0,001 м,
чтобы разметка не мерцала на совпадающей поверхности основного пола.

На земле стоят четыре низких цилиндра высотой 0,45 м и радиусом 0,65 м:

| Положение центра, м | Цвет |
| --- | --- |
| X = 25, Y = 0 | Оранжевый |
| X = −25, Y = 0 | Фиолетовый |
| X = 0, Y = 25 | Зелёный |
| X = 0, Y = −25 | Жёлтый |

Все цилиндры опираются на землю. Центральная область от −15 до 15 м
по каждой горизонтальной оси свободна от объёмных ориентиров.
Фигур над аппаратами и объектов, следующих за ними, нет.

Это статическая визуальная модель: она не содержит столкновений,
плагинов, датчиков или собственной публикации эталонных координат.
Ориентиры служат для наблюдения, а не задают физические препятствия
для планировщика. Тени от всей разметки и цилиндров выключены.

Вся сетка вместе с фоном и осями содержится в одном файле
`meshes/grid.dae`, одной геометрии и одном элементе отображения модели.
В ней 808 треугольников. Толстые и тонкие линии отличаются шириной;
на их пересечениях используется одинаковый материал. Разноцветные оси
отделены от обычных линий, а в центре приоритет имеет красная ось X.
Растровых изображений и внешних текстур нет.

Геометрия воспроизводится стандартным Python без дополнительных библиотек:

```bash
python3 src/swarm_lidar/models/training_ground/generate_grid.py
gz sdf -k src/swarm_lidar/models/training_ground/model.sdf
```

Генератор изменяет только `meshes/grid.dae`. При установке пакета нужно
сохранить вложенный каталог `models/training_ground/meshes`, чтобы URI
`model://training_ground/meshes/grid.dae` разрешался корректно.
Модель включена в оба штатных мира: `swarm.sdf` и `swarm_lidar.sdf`.
Разметка появляется при следующем запуске симуляции. Параметры полёта
и управления при этом не меняются.

## Столбы-препятствия

На площадке стоят шесть физических столбов (модель `pillar`: радиус 0,6 м,
высота 10 м): стена из четырёх на x = 18 м (y = −12, −4, 4, 12) и два
отдельных — (−15; 15) и (8; −20). Единственный источник положений —
`swarm_lidar/config/obstacles.yaml`; тест `test_pillars.py` сверяет с ним
оба мира Gazebo. `training_map` помечает занятыми клетки, которых касается
столб, поэтому A* обходит их с запасом под весь строй (радиус строя +
0,75 м). Промежутки стены (8 м) уже этого запаса, поэтому к цели за стеной,
например (35; 0), маршрут идёт вокруг её края. Панель рисует занятые клетки
карты.

LiDAR видит столбы, но не путает их с ведомыми: в полосу поиска попадает
около 1,9 м высоты столба, а кластеры протяжённее 1,5 м отбрасываются.
