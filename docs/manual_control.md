# Ручное управление ведущим из панели

Блок «Сценарий 2 · Ручное управление» браузерной панели передаёт команды уже
взлетевшему ведущему. Три ведомых продолжают сопровождать его по LiDAR и
контроллеру строя. Пульт не вооружает аппараты, не выполняет взлёт и не
сажает группу: для этого служат кнопки полёта вверху страницы.

## Подготовка

Запустите симуляцию и панель (см. [web_panel.md](web_panel.md)), нажмите
«Подготовить и взлететь» и дождитесь готовности группы. Сессия оператора
записывает rosbag и метрики, если отмечено «Сохранять измерения полёта».

Кнопки движения доступны, только если ведущий вооружён, находится в Offboard
(`nav_state` 14) и выше 1 м над нулём карты. Первое нажатие запрашивает у
`leader_interface` режим MANUAL через `/leader/manual`. Узел отклоняет
запрос, если строй не готов; причина показывается в панели.

## Кнопки

| Кнопка | Действие |
| --- | --- |
| ↑ / ↓ | Вперёд / назад по курсу ведущего |
| ← / → | Влево / вправо относительно курса ведущего |
| ↺ / ↻ | Поворот против / по часовой стрелке, 0,3 рад/с |
| Выше / Ниже | Подъём / снижение, 0,5 м/с |
| ■ Стоп | Удержание ведущего (HOLD) |
| 0,5 / 1 / 1,5 | Горизонтальная скорость, м/с |

Направления считаются относительно текущего курса ведущего: «вперёд» —
куда он смотрит. Ведомые держат тот же курс, поэтому строй при повороте
разворачивается вместе с ведущим. Диагональные сочетания не используются:
одна кнопка — одно направление. Ниже 1 м снижение не выдаётся.

## Защита

Пока кнопка нажата, браузер повторяет команду каждые 0,1 с. Сервер панели
публикует `TwistStamped` в `/leader/cmd_vel` (`frame_id=map`, ENU, отметка
часов симуляции) на каждом шаге своего таймера 0,05 с:

- без повтора дольше 0,3 с (кнопка отпущена, вкладка закрыта, сеть
  остановилась) публикуется нулевая скорость: ведущий тормозит через свои
  ограничения ускорения и рывка;
- через 3 с после последней команды публикация прекращается, и узел
  ведущего сам переходит в DEADMAN по `manual_timeout`;
- команды не публикуются без свежей телеметрии ведущего или при
  остановившихся часах симуляции.

Ограничения скорости `leader.yaml` (1,5 м/с, 1 м/с², 2 м/с³, 0,3 рад/с) и
общее ограничение скорости мест строя действуют как прежде.

Перестроение и маршрут к точке берут управление у пульта: перед сменой строя
нажмите «■ Стоп», маршрут из блока карты сам переводит ведущего в MISSION.

## Завершение

«Посадить всех» прекращает ручные команды, переводит ведущего и строй в
удержание и сажает группу. Запись сохраняется в `log/web/operator_*/flight`.
