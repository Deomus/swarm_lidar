# Проверенные версии зависимостей

Прогоны из [отчёта](experiments.md) выполнялись на Ubuntu 24.04 с ROS 2
Jazzy и Gazebo Harmonic 8.15.0. Для повторения важна согласованная версия
PX4 и его сообщений, поскольку имена тем и состав сообщений меняются.

| Компонент | Проверенная версия |
| --- | --- |
| PX4 Autopilot | `878877ad022109cc4af7fea566efa0692c43813c` |
| px4_msgs | `2e892300d8c20d3c29e198e324a10854b40ab8d3` |
| Micro XRCE-DDS Agent | `v3.0.2` |
| ROS — Gazebo | `ros-jazzy-ros-gz 1.0.24` |
| rclpy | `7.1.12` |
| gz-transport Python | `13.6.0` |
| gz-msgs Python | `10.4.0` |
| NumPy | `1.26.4` |
| SciPy | `1.11.4` |
| Matplotlib | `3.6.3` |
| pymavlink | `2.4.50` |

Исходники PX4: <https://github.com/PX4/PX4-Autopilot>.
Сообщения: <https://github.com/PX4/px4_msgs>.
Агент: <https://github.com/eProsima/Micro-XRCE-DDS-Agent>.

Таблица фиксирует рабочее окружение, а не утверждает, что каждая другая
версия несовместима. Другие сочетания отдельно не проверялись. Установка
на чистой отдельной системе пока не подтверждена; проверены сборка текущего
репозитория и перечисленные прогоны. Выбор точных ревизий выполняется до
сборки внешних компонентов, с обновлением подмодулей PX4.

Для контроля версий используйте `git rev-parse HEAD` в каталогах исходников,
`gz sim --version` и системный менеджер пакетов. ROS 2 Jazzy проверяется
командой `ros2 --help`: у его CLI нет команды `ros2 --version`.

Узел программной наземной станции использует `pymavlink`. Зависимость
объявлена в `autopilot_bridge/setup.py` и через ключ `python3-pymavlink-pip`
в манифесте ROS. Это ключ установки Python-пакета через pip, а не имя
пакета apt; соответствие задано в [правилах rosdep](https://github.com/ros/rosdistro/blob/master/rosdep/python.yaml).
Наличие библиотеки в подготовленной системе не заменяет проверку её
установки в новой среде.
