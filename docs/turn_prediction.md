# Упреждение при повороте строя

> Историческое описание: прогноз удалён 22 октября; упреждение теперь берётся
> из заданной команды ведущего, см. [formation.md](formation.md).

При повороте ведущего меняется положение каждого места относительно мира.
Даже если ведущий стоит, ведомые должны двигаться по дугам. Скорость места
складывается из скорости ведущего, скорости перестроения и скорости
вращения смещения вокруг ведущего. Последняя равна векторному произведению
угловой скорости и смещения, переведённому в координаты мира.

Раньше упреждение оценивало только изменение скорости ведущего. Скорость
движения места при повороте проходила через два сглаживающих звена без
упреждения. Это создаёт дополнительное отставание, особенно у дальних мест.

Параметр `predict_slot_motion` позволяет оценивать ускорение полного движения
места отдельно для каждого ведомого. Поправка применяется до общего
ограничителя скорости, ускорения и рывка. Пространственная ошибка регулятора
и отталкивание при сближении не входят в прогноз ускорения.

Упреждение включается только при свежем действительном намерении ведущего
в ручном режиме или при исполнении миссии. В удержании история сбрасывается.
Остановка из-за недостоверных данных сохраняет прежний приоритет.
Параметры плавности перестроений и предельные скорости не меняются.

Проверка на идеальной модели вращения на месте сравнивает исходное
сопровождение с упреждением движения места и проверяет ограничения команды.
Это проверка алгоритма, а не модель физики PX4. Полётные результаты следует
сравнивать отдельно, с одинаковой последовательностью команд.

## Первый полётный опыт

В S2 при `predict_slot_motion=true` среднеквадратичная ошибка строя
снизилась с 0,797 до 0,736 м относительно предыдущего запуска на площадке
с сеткой. Минимальная дистанция составила 3,357 м вместо 3,312 м.
При этом максимальная ошибка выросла с 2,220 до 2,295 м. Одного опыта
недостаточно для вывода об устойчивом улучшении.

| Заданная скорость ведущего | Прежний RMS | RMS с прогнозом места |
| --- | --- | --- |
| 0,5 м/с | 0,670 м | 0,614 м |
| 1,0 м/с | 0,781 м | 0,745 м |
| 1,5 м/с | 0,922 м | 0,840 м |

Окно каждой скорости включает прямую, поворот, снижение и остановку.
Поэтому таблица не описывает установившееся прямолинейное движение.
Данные: `log/s2_slot_prediction_1`, видео с тем же именем и расширением
`.mp4`, компактный [отчёт](../examples/results/s2_slot_prediction_1.json).
Все аппараты сели; при потере передачи на 0,7 с нулевые команды
подтверждены через 0,404 с. Параметры работающего контроллера сохранены
в `controller_parameters.yaml` внутри каталога прогона.

## Повтор после нового запуска мира

Во втором независимом запуске получены RMS 0,727 м, максимум 2,335 м,
минимальная дистанция 3,369 м. RMS по трём окнам — 0,600 / 0,736 / 0,843 м.
Все аппараты сели; реакция на потерю передачи — 0,404 с. Данные:
`log/s2_slot_prediction_2`, [компактный отчёт](../examples/results/s2_slot_prediction_2.json).

Два запуска дают уменьшение RMS примерно на 8–9% относительно исходного
прогона, но максимум ошибки вырос на 3–5%. Это улучшение средней точности
сопровождения, а не уменьшение всех ошибок. В штатном YAML включён
`predict_slot_motion=true`; значение `false` возвращает прежний прогноз
только переноса ведущего для сравнения. Коэффициент ошибки 0,3 и пределы
2 м/с, 4 м/с², 8 м/с³ сохранены. Двух запусков недостаточно для
статистического вывода о надёжности; переходные максимумы требуют настройки.

## Проверка перестроений

S1 на площадке с сеткой завершился всеми переходами и посадкой:
RMS строя 0,216 м, максимум 0,686 м, минимальная дистанция 2,758 м.
Устаревших относительных измерений в активных выборках нет.
По сравнению с прежним S1 RMS практически не изменился (0,216 м).
Данные — `log/s1_slot_prediction`, видео с тем же именем; метрики
[сохранены отдельно](../examples/results/s1_slot_prediction.json).
Проверка четырёх PX4, устойчивых трёх целей настоящего LiDAR и
синтетической цепочки с остановкой облака также пройдена.

## Проверка автоматического маршрута

S3 после S1 в том же мире завершился достижением цели и посадкой всех
аппаратов. RMS строя — 0,154 м, максимум — 0,358 м, минимальная дистанция —
3,853 м. RMS отклонения ведущего от маршрута — 0,401 м, максимум — 0,761 м.
Конечная ошибка по PX4 — 0,301 м, по эталону — 0,410 м; эталонный снимок
отстоит от события на 0,004 с. Этот опыт проверяет работоспособность миссии;
разницу с прежним S3 нельзя приписывать только новому прогнозу.

Данные — `log/s3_slot_prediction`, видео с тем же именем.
Сохранены [метрики сценария](../examples/results/s3_slot_prediction.json)
и [конечная ошибка](../examples/results/s3_slot_prediction_goal.json).
Видео всех четырёх новых прогонов S1/S2/S2/S3 полностью декодируются.
