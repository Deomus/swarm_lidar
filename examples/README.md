# Примеры результатов

В `results/` сохранены небольшие JSON-отчёты реальных прогонов. Большие
облака LiDAR, MCAP и видео остаются в локальном `log/` и в Git не добавляются.
В отчётах доступны общие метрики, активное управление, отдельные фигуры
и временные окна команд. Единицы расстояния — метры, времени — секунды.

`s1_recorded.json` и `s2_recorded.json` сняты с упреждением скорости до
его последующего отключения в HOLD. Они не являются результатами текущей
конфигурации после всех изменений. `passed` подтверждает последовательность
сценария и посадку, а не прохождение отдельного критерия точности.

В `overall_metrics` есть взлёт и посадка; для управления смотрите
`active_control`, для удержания — `following_by_formation`.
Полное описание условий и ограничений — в [отчёте](../docs/experiments.md).
